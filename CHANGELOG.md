# История изменений

## 1.2.0

- Текущая рабочая версия перенесена под название LipatoS.
- Внутренний ID изменён на `lipatos-player-level-edit`.
- Классы интерфейса переименованы с Aindor на LipatoS.
- Сохранён синхронизируемый тумблер редактирования уровня.
- Включать и выключать разрешение по-прежнему может только ГМ.
- Добавлен перенос старого флага `aindor-player-level-edit` в новый `lipatos-player-level-edit`.
- Сохранена совместимость с модулем **LipatoS-player-features-lock**.
