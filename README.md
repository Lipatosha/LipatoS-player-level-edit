# LipatoS — редактирование уровня

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который добавляет синхронизируемый тумблер разрешения на редактирование уровня персонажа.

Тумблер видят и игрок, и ГМ, но менять его состояние может только ГМ. Разрешение хранится непосредственно на персонаже и одновременно применяется в интерфейсе ГМ и владельца персонажа.

## Версия

**1.2.1**

## Совместимость

- Foundry VTT: **14.367**
- D&D 5e: **6.0.0–6.0.5**

## Возможности

- добавляет тумблер **«Редактировать»** во вкладку **«Особенности»**;
- включать и выключать разрешение может только ГМ;
- игрок видит текущее состояние разрешения;
- состояние синхронизируется через флаг персонажа;
- разблокируется только вкладка **«Особенности»**, остальные вкладки не становятся редактируемыми;
- поддерживает перенос состояния со старого модуля `aindor-player-level-edit`;
- работает совместно с **LipatoS-player-features-lock**.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-player-level-edit/main/module.json`
